# v5.9.54 — Clean Up Song Storybook Player

- Clean Up Song now opens inside the Companion instead of only starting audio.
- Uses approved Early Eagle Academy watercolor cleanup artwork.
- Adds a video-like sequence of Eddie cleaning with gentle scene changes.
- Displays the song lyrics one line at a time, with the next line previewed for early-literacy support.
- Adds Play, Pause, Restart, progress, time, and volume controls.
- When the song ends, the player automatically transitions to a Circle Time screen.
- Tapping the Circle Time screen returns to the classroom dashboard.
