# Centers Copy Rendering Rule

The reusable Centers renderer now prevents duplicate child-facing copy.

Rules:
- Opening card: intro heading + center/activity list once.
- Individual center cards: activity subtitle + one child-facing prompt.
- Closing card: one closing/transition message only.
- If subtitle and prompt normalize to the same text, the secondary copy is suppressed automatically.

This applies to future Centers lessons generated by the shared component.
