# Read Aloud Book Registry v1
- Supplied adapted pages are registered once per book.
- Read Aloud lessons automatically receive registered pages if their cards contain only prompts/activities.
- Explicit book cards remain authoritative.
- Missing registrations display BOOK PAGES MISSING rather than silently omitting the book.
- Registered pages inherit the global approved Read Aloud placement rule.
- Vocabulary remains a separate component.
