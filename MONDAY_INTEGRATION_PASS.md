# Monday Integration Pass — v5.10.05

Purpose: make Week 1 Monday behave as one continuous classroom teaching experience.

Verified/standardized flow:
Morning Setup → Today's Lesson Path → Community Meeting → Read Aloud → Centers → Storytelling → Closing Circle → Day Complete.

Integration rules:
- Each curriculum component retains its own internal Next/Back sequence.
- Completion returns control to the shared Today's Lesson Path.
- Center Choice remains an optional branch from the Centers Ready screen.
- Teacher tools remain separate from lesson completion state.
- Closing Circle is the terminal instructional component.
- Completing Closing Circle produces a dedicated Day Complete state rather than presenting another lesson card.
- A teacher can return from Day Complete to Today's Lesson Path to review completed activities.
- No curriculum data was changed during this integration pass.

Visual polish remains intentionally flexible.
