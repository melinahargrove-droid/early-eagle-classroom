# Early Eagle Academy Companion v4.0 — Dashboard Rebuild

- Rebuilt the Home dashboard as a true 1920×1080 app surface instead of a single flattened dashboard image with invisible hotspots.
- Removed Eddie from the permanent header while keeping him as a classroom character in the What's Next area.
- Eliminated the doubled left/right edge effect by using the classroom environment as a full-bleed 16:9 background.
- Schedule items are now real controls and update What's Next.
- Classroom timer is functional (plus/minus, start, pause, reset).
- Choose a Friend is functional and avoids repeats until reset.
- Star of the Day remains connected to Teacher Mode and the saved class list.
- Clean Up Song plays the bundled audio or can open a teacher-provided URL.
- Daily Lessons can open a teacher-provided URL.
- End Day resets daily schedule/timer/name-picker state.
- Teacher Mode now edits students, Star of the Day, schedule, media links, sound, fullscreen, and install options.
- Existing v2/v3 local classroom data is migrated into v4 when available.
