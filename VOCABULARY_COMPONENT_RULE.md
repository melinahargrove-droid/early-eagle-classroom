# Vocabulary Definition Component — Locked Rule

Every vocabulary card must render through the shared vocabulary component:

1. Vocabulary word
2. Short preschool-friendly definition
3. REQUIRED meaningful visual example
4. Optional **Try It!** action when movement/modeling helps teach meaning

Rules:
- Emoji-only vocabulary cards are prohibited.
- A vocabulary card without `img` triggers a development error and an obvious missing-visual state.
- Book-reading cards remain separate and keep the approved large-book layout.
- Vocabulary definitions never share space with a Read-the-Story spread.
- Apply this component to all future Daily Lessons vocabulary/definition slides.
