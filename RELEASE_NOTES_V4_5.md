# Early Eagle Academy Companion v4.5

Schedule panel functional polish while preserving the locked Home Dashboard visual master.

- Removed **Add Activity** from the Home dashboard; schedule editing remains in Teacher Mode.
- Made schedule progress sequential so the pale-blue highlight always marks the true next activity.
- Tapping a future/current row completes the schedule through that row; tapping a completed row reopens that row and everything after it.
- Removed browser focus/hover artifacts that could make the wrong schedule row appear highlighted.
- Updated schedule row typography to a softer, more child-friendly system font stack.
- When every schedule item is complete, the What’s Next panel now shows **All Done!** instead of pointing back to the last completed activity.
