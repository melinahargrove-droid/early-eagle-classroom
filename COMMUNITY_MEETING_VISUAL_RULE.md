# Community Meeting Visual Rule

Each generated Community Meeting teaching card should include a large, child-friendly visual tied directly to the activity.

Visuals are selected by `visualKey` in the curriculum-driven flow:
- `belly-breaths` → child breathing with belly-expansion cues
- `school-feelings` → children talking/expressing feelings about school
- `name-ball` → children and a clearly featured Name Ball
- `classroom-community` → group/community completion visual

The visual is part of the reusable Community Meeting component, not hard-coded to one screen. Future weeks should provide an appropriate `visualKey` for each activity.
