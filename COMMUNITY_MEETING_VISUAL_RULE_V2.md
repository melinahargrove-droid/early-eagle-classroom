# Community Meeting Visual Rule v2

Whenever an activity can be demonstrated physically, use a large child-facing storybook visual showing a child actually doing the activity.

Priority:
1. Dedicated storybook demonstration visual (`visual`)
2. Reusable symbolic fallback (`visualKey`) only when a dedicated demonstration visual is not yet available

Examples:
- Belly Breaths → child seated calmly with hands on belly and breathing cues
- Yoga/poses → child visibly demonstrating the actual body position
- Name Ball → children sitting together passing/holding the ball
- Movement games → child/children visibly performing the movement
- Conversation prompts → contextual scene supporting the discussion

Dedicated visuals live inside the reusable Community Meeting component and never become separate lesson slides.
