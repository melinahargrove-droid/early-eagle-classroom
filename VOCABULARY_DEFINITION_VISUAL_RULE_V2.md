# Vocabulary Definition Visual Rule — v2.0

## Permanent rule
Every vocabulary/definition slide must use the shared vocabulary component:

**Word → short preschool-friendly definition → dedicated meaningful visual example → optional Try It!**

### Visual requirements
- The visual must directly teach the meaning of the vocabulary word.
- Prefer a **dedicated concept visual** created specifically for that word.
- Show the meaning in context or action whenever possible.
- Do **not** reuse a Read-the-Story book spread as the vocabulary visual when the spread includes unrelated page text, page numbers, or book furniture.
- A book illustration may be used only if it can be cleanly isolated as the concept visual without showing unrelated book text/page furniture.
- Emoji-only vocabulary visuals are prohibited.
- Visuals must be large enough to understand from the SmartBoard.

### Layout requirements
- Vocabulary always appears on its own slide after the relevant book spread.
- Vocabulary content may never reduce the size of a Read-the-Story book slide.
- Movement/modeling cues belong in an optional **Try It!** panel on the vocabulary slide.

### Validation
The app flags vocabulary cards that:
1. have no visual, or
2. still point directly to a Read-the-Story book-spread asset.
