# Community Meeting Curriculum Data Model

Community Meeting is now generated from:
`Unit → Week → Day → Community Meeting`

Week 1 verified curriculum:
- Mindful Practice: Belly Breaths
- Conversation: How do you feel about starting school this year?
- Movement/Game: Name Ball
- Guiding Question: How do we make a community?

The shared component generates a four-card teaching flow:
1. Mindful Practice
2. Conversation
3. Movement/Game
4. Completion/transition

Future weeks/days should be added to `curriculumData`; the renderer should not be rewritten for each lesson.
