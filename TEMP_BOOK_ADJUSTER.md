# Temporary Book Adjuster

Use the floating Book Adjuster while viewing a Read-the-Story book spread.

- **Size** enlarges/reduces the white frame and book together.
- **Left / Right** moves the book horizontally.
- **Up / Down** moves the book vertically.
- **Copy Placement** copies a simple readout such as `Size 118% • X -24 • Y 16`.
- **Reset** returns to the v5.9.74 position.
- Settings persist locally while testing.

Send the final Size, X, and Y values back so they can be locked into the app and this temporary panel removed.
